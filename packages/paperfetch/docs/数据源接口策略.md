# 数据源接口策略

API 的作用是获取事实，不是替代 Agent 理解主题。

所有来源共享的限流、缓存、权威 404 与临时错误契约见
[元数据调度与缓存架构](元数据调度与缓存架构.md)。429、超时和 5xx 不得作为“未找到”。

## 1. 默认元数据源

### OpenAlex

用途：

- 宽覆盖论文元数据。
- DOI、title、year、venue。
- citation count。
- OA status 线索。

默认启用。

### Crossref

用途：

- DOI 和 publisher metadata。
- venue / ISSN。
- license / full-text URL 线索。

默认启用。

### Semantic Scholar

用途：

- CS / AI / 工程方向论文。
- abstract。
- citation / reference。
- related paper signal。

CS 方向默认启用。

## 2. 后续增强源

### DBLP

用途：

- CS 论文身份。
- conference / journal 信息。
- venue 质量交叉检查。

### arXiv

用途：

- 预印本。
- PDF。
- AI / CS 新方向覆盖。

### DataCite

用途：

- dataset DOI。
- software DOI。
- benchmark artifact。

### ROR

用途：

- 作者机构归一化。
- 学术/工业/政府机构判断。

### CORE

用途：

- repository OA full text。
- PDF 候选。

## 3. OA / PDF

### Unpaywall

只用于 DOI enrichment。

用途：

- OA status。
- license。
- PDF URL candidate。

不能作为普通关键词搜索源。

## 4. PDF 下载规则

只有满足以下条件才下载：

- OA 或明确许可。
- PDF URL 来自可信 source。
- content-type 合理。
- 文件开头是 `%PDF`。
- 文件大小不超过限制。

失败必须记录原因：

- `NO_DOI`
- `NO_OA_LOCATION`
- `PDF_URL_MISSING`
- `LICENSE_RESTRICTED`
- `NOT_A_PDF`
- `PDF_TOO_LARGE`
- `DOWNLOAD_FAILED`
