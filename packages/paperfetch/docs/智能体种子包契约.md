# Seed Pack 契约

Seed Pack 是 Agent 或用户为一个研究主题整理的论文包：元数据、已验证 PDF 与 MinerU 正文
共同存放，并由 SPC 原子维护。参数以 `spc seed-pack --help` 与
`spc schema seed-pack <action>` 为准。

## 分工

1. Agent 自己判断选题方向（SPC 不自动选种）。
2. 用只读 `spc paper search` / `spc paper graph` 拿候选。
3. 显式 `spc seed-pack add` 写入候选，再 `spc seed-pack enrich` 获取文件。

## 命令

```text
spc seed-pack init   --seed-pack <dir> [--name <name>]
spc seed-pack show   --seed-pack <dir>
spc seed-pack add    --seed-pack <dir> --doi <doi> [--pubmed-id ...] [--pmc-id ...] [--arxiv-id ...] [--detach]
spc seed-pack enrich --seed-pack <dir> [--doi <doi>] [--failed-only|--download-only|--parse-only] [--no-cache] [--detach]
```

- `add` 只接受强标识（DOI、PMID、PMCID、arXiv ID），只写元数据。
- `enrich` 获取并验证 PDF，再解析正文；`--parse-only` 只重试解析。
- 并发写入由 Seed Pack 锁串行化；超时由 `--lock-timeout-seconds` 控制。

## 目录与事实源

```text
seed-pack/
├─ manifest.json
├─ papers.jsonl
├─ artifacts/<paper-id>/
│  ├─ pdf/<sha-prefix>/article.pdf
│  └─ fulltext/mineru-<version>-<pdf-sha-prefix>/...
└─ .spc/{transactions,staging,locks,audit}/
```

- `papers.jsonl` 是论文事实的唯一权威文件，不得手工编辑。
- PDF、Markdown 等文件由文件清单记录相对路径、字节与 SHA-256。
- 每次更新都是“读取最新记录、合并、校验实际文件、暂存、原子替换、重新读取”。
- `spc seed-pack show` 会重载记录并检查实际文件，而不是信任缓存的状态字段。
- 旧 0.x `seed_papers.jsonl` 包返回稳定不支持错误，不静默迁移或混写。
- `spc paper parse` 的输出不绑定论文身份，不能直接写入 `papers.jsonl`。
