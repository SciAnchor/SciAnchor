# publication-pack

Assemble an evidence-bound publication package from RH topic artifacts.

This skill is inspired by the contract-first pattern used by specialized academic-output skills: define the package and QA obligations before generating polished writing, figures, slides, or reviewer responses.

The canonical machine-readable artifact is `publication_pack`, generated by the `publication_pack_generate` primitive when available.

Local CLI convenience:

```bash
rh publication-pack generate --topic "<topic-name>" --record-artifact
rh --json publication-pack generate --topic "<topic-name>" --record-artifact
```

## Typical trigger

```text
把这个 RH topic 整理成投稿材料包，并告诉我还缺什么。
```

## Canonical components

- Required: `draft_pack`, `evidence_pack`
- Recommended: citation/integrity report, figure plan, data availability, reviewer response, slides outline, final bundle, process summary

See [`references/contract.md`](references/contract.md) for the artifact shape.
